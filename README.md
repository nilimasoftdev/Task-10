# Laundry Mart - Responsive Website

## About the Project

This is a Laundry Mart landing page created using HTML and CSS.

I created this webpage as part of my assignment to practice responsive web design, Flexbox, CSS animations, and media queries.

The website includes a navigation bar, a hero section with text and an image, and a hamburger menu for mobile screens. The hamburger menu opens a navigation list using the CSS `:focus` pseudo-class without using JavaScript.

## Files in the Project

- `index.html`
- `style.css`
- `image_5abe01cb-removebg-preview.png`
- `Readme.md`

## Features

- Responsive design for desktop, tablet, and mobile screens
- Navigation bar with Home, Services, About Us, and Contact Us links
- Hamburger menu for mobile screens
- Right-side navigation menu
- CSS hover animation on the service button
- CSS animation on the laundry image
- Responsive hero section

## Technologies Used

- HTML
- CSS
- Flexbox
- CSS Media Queries
- CSS Animations

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser to view the webpage.
